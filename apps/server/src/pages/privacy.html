Privacy

Unbait is open source, so everything below can be checked in the code.

Rules only (the default)

Posts are checked by pattern rules inside your browser. Nothing is sent anywhere.

Rules + AI

  • Only posts the rules can't decide are sent to this server, as plain text.
  • Names of people tagged in a post are replaced with "@someone" before sending. Author names, profile details, your own account and your messages are never read or sent.
  • The server sends the text to Anthropic's Claude API to classify it, and keeps only a SHA-256 hash of the text with the verdict, so the same post isn't classified twice. The text itself is not stored or logged.
  • Your extension sends a random install id, used only for rate limits; the server stores a hash of it.
  • "Not bait?" reports store the post's hash, what Unbait decided, and the hashed install id.

In your browser

The extension stores your settings, its counters, and hashes of posts it has seen, in Chrome's extension storage. It only runs on linkedin.com and asks for no other permissions.
