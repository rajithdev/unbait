Unbait

A browser extension that folds away engagement bait in your LinkedIn feed: comment-to-get giveaways, "Agree?" posts, cliffhanger stories and hype lists. This is its API server.

–posts checked by the AI
–bait posts caught
–"not bait" reports

Get the extension

Download it from the latest release, or read the code on GitHub.

What this server sees

Only the text of posts the extension's local rules couldn't decide, and only when you switch on "Rules + AI". Names of people tagged in a post are removed before sending. The server keeps a hash of each post and its verdict, never the text. Privacy details.

API: POST /v1/classify · POST /v1/report · GET /v1/stats · GET /health
